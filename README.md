# SSAS downloads

This branch (`main`) is the download page **https://ssas.ae**. Hostinger publishes it. It is one file: `index.html`.

- New versions appear on the page by themselves, because it reads the GitHub releases.
- The list written in `index.html` is used only when GitHub cannot be reached.

The apps are on branch `claude/smart-student-attendance-189mro`. Never merge that branch into `main`, or the code would be published on the website.
